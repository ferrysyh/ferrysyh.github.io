How it works

  1. Select one or more JSON response files.
  2. Click Extract Unique URLs.
  3. Review the extracted URLs.
  4. Download the result as a TXT file.
Privacy: All processing happens locally in your browser. Files are not uploaded to a backend, and this tool does not send requests to the extracted endpoints. Use only data you are authorized to analyze.
  • Only absolute HTTP/HTTPS URLs are included.
  • Exact duplicate URL strings are removed.
  • Different query parameters remain distinct.
  • Different query parameter orders remain distinct.
  • Relative paths such as /api/users are ignored.
  • URLs inside nested JSON objects and arrays are supported.
